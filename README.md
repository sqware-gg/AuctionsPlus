# Auctions+

Auctions+ is a Paper auction house plugin built around fixed-price listings, Vault-backed economy transactions, GUI browsing, expiry returns, and claim mail.

## Commands

- `/ah` opens the auction browser.
- `/ah sell <price> [amount] [duration]` lists the item in your hand.
- `/ah active` opens your active listings.
- `/ah claim` opens claim mail for purchased, cancelled, and expired items.
- `/ah search <text>` opens a filtered browser.
- `/ah cancel <id>` cancels one of your active listings.
- `/auctionsplus stats|reload|save|cancel <id>` manages the plugin.

## Requirements

- Paper compatible with the configured API version.
- Vault and a Vault-compatible economy plugin.
- Java 25 or newer.
